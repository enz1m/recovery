# Contributing to Recovery

Use shared enzUI widgets and theme settings. Keep blocking work off the UI thread
and preserve cancellation, credential handling and file integrity.

Run the formatting, test and Clippy commands in the README. Test UI changes in
demo mode in light and dark appearance, including at narrow window sizes.
Use a disposable VM and synthetic data for tests that exercise the native
installation or recovery helpers.

Put README screenshots in `docs/screenshots/`. Keep local theme presets and
review logs outside the repository.
